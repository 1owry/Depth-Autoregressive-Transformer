# Depth-Autoregressive-Transformer

This project presents a Depth-Autoregressive Transformer for three-dimensional soil organic carbon (SOC) mapping. The proposed framework incorporates autoregressive prediction to leverage SOC information from adjacent soil layers and introduces soil knowledge-guided constraints to improve prediction accuracy and stability across different depths.

## Paper

Lu, R., Guo, H., Chen, Z., Chen, T., Shi, Z., & Chen, S. (2026). Soil Knowledge-Guided Depth-Autoregressive Transformer for Predicting Soil Organic Carbon at Multiple Depths. *IEEE Transactions on Geoscience and Remote Sensing*.

DOI: https://doi.org/10.1109/TGRS.2026.3736571
